# استقرار سرور (Cloudflare Worker)

سرور کوچکی که توکن گیت‌هاب را **مخفی** نگه می‌دارد و داده هر مشتری را روی گیت‌هاب شما ذخیره می‌کند.

## ۱) حساب Cloudflare (رایگان)

1. <https://dash.cloudflare.com/sign-up> — ثبت‌نام رایگان
2. تأیید ایمیل

## ۲) توکن دسترسی Cloudflare

1. <https://dash.cloudflare.com/profile/api-tokens>
2. **Create Token** → الگوی **Edit Cloudflare Workers** را بزنید
   - یا Create Custom Token با مجوزهای:
     - Account → Workers Scripts → Edit
     - Account → Workers R2 → Edit (اختیاری)
3. **Continue to summary → Create Token**
4. متن توکن (`…`) را کپی کنید

## ۳) استقرار از این پوشه

```bash
cd worker

# ورود با توکن
export CLOUDFLARE_API_TOKEN=YOUR_CF_TOKEN
export CLOUDFLARE_ACCOUNT_ID=YOUR_ACCOUNT_ID   # از داشبورد Cloudflare

# (حساب و شناسه اکانت در تب Workers یا API /members/me/accounts)

# سرور توکن گیت‌هاب
npx wrangler secret put GITHUB_TOKEN
# مقدار: همان توکن گیت‌هاب با دسترسی repo

# انتشار
npx wrangler deploy
```

آدرس خروجی شبیه این است:

```
https://gamenet-server.<something>.workers.dev
```

## ۴) وصل کردن سایت به سرور

در `../index.html` خط `window.GAMENET_API = ...` را با آدرس Worker پر کنید، سپس فایل‌ها را روی گیت‌هاب push کنید.

## ۵) تست

```bash
curl https://<worker>/api/health
# باید {"ok":true}
```

## مسیر داده‌ها روی گیت‌هاب شما

```
data/db/users.json              ← حساب مشتری‌ها (رمز هش‌شده)
data/db/customers/{id}.json     ← داده‌های هر مشتری (جدا از بقیه)
```
